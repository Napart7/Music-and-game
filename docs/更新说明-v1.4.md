## 一、这一版改了什么

### 1. 歌词偏移快捷微调热键（新）

以前歌词和声音差半拍，只能开菜单 → 视觉 → 拖动时间轴滑块，游戏中被打断很烦。现在两个全局热键解决：

| 热键 | 作用 | 什么时候按 |
|---|---|---|
| `Ctrl + Alt + PageUp` | 歌词**提前** 0.1 秒 | 蓝牙耳机声音比画面慢，歌词老是慢半句 |
| `Ctrl + Alt + PageDown` | 歌词**延后** 0.1 秒 | 歌词抢在唱之前，像提前剧透 |

- 步进 100ms，范围 ±3000ms，连按可快速累积；到边界会停在 ±3000ms
- 与「视觉」页的时间轴滑块**共用同一份配置**，热键调完打开菜单能看到滑块同步移动
- 可在「通用 → 全局热键」重绑定；若被其它软件占用，按钮上会标「占用」
- 记法：`PageUp` = 往上赶 = 更早；`PageDown` = 往后拖 = 更晚

**典型场景**：蓝牙耳机（100–300ms 延迟）按 1–3 次 `PageUp`；有线音箱多声道延迟按 1–2 次 `PageDown`；HDMI 接电视（电视芯片补帧常加 80–200ms）也按 `PageUp`。

### 2. 屏幕轻提示 Toast（新）

用热键调偏移时，屏幕下方浮出一条 1.7 秒的提示，例如：

```
        歌词偏移 +200 ms（更早）
```

- 位置：屏幕下方 9% 居中，胶囊形，毛玻璃底
- **点击穿透**、不挡操作、不开菜单也能看见
- 菜单打开时自动隐藏（面板正好盖住这个区域，不抢视觉焦点）
- 只用一条 CSS 过渡，不新增动画循环 —— 暂停 / 隐藏时依然零开销

### 3. 「关于」页现在说真话（修）

之前版本号写死成 `1.0.0 · 六平台适配`，实际早就 1.4 了。现在全部运行时读取：

| 字段 | 来源 |

| 运行平台 | 平台 + 架构 + Electron 版本，如 `Windows · x64 · Electron 33.x` |

### 4. 「最近更新」卡片 + 程序内更新日志（新）

关于页新增卡片，直接显示最近 3 个版本的要点，不用去 GitHub 翻。

## 六、升级指引

1. **覆盖安装**：直接跑新版安装包即可，`config.json`、歌词位置、热键、歌词缓存全部保留（配置在 `%APPDATA%\glasslyrics\`，macOS 在 `~/Library/Application Support/glasslyrics`，Linux 在 `~/.config/glasslyrics`）。
2. **新热键被占用**：打开菜单 →「通用」→ 找到「歌词提前 / 延后 0.1 秒」，按钮显示「占用」就点它重新绑定（例如换成 `Ctrl+Shift+PageUp`）。
3. **偏移调乱了**：两种复位方式 —— 连按反向热键回到 0；或打开「视觉」→ 时间轴滑块拖回 0（滑块与热键同步）。
4. **想关掉提示条**：Toast 只在热键操作时出现，不做常驻；若不想看，把两个偏移热键清空即可（点击按钮 → Delete）。
5. **从 0.8 / 0.9 升级**：务必升到 1.4.0，0.9.0 存在「切屏回来吞点击」的缺陷。

## 七、v1.4.1 修复：托盘菜单与窗口层级

这一版针对「右键托盘图标，菜单出来又消失」和「打开别的软件时覆盖层压住它」做的排错，
结论是一颗每 2 秒执行的心跳在反复重设窗口样式：

| 修复项 | 说明 |
|---|---|
| 托盘菜单按需构建 | Windows / macOS 改为点击时才构建菜单，后台状态变化不再替换（替换即关闭）正在显示的菜单 |
| 心跳加守卫 | 只在 `isFocusable()` 显示穿透确实失效时才调用 Win32；空闲 8 秒的窗口级调用从 4 次降为 **0 次** |
| 层级分级 | 捕获到游戏窗口用 `screen-saver`；非游戏前台降为 `floating`，系统/托盘/应用菜单永远在上 |
| 分类模块化 | 新增 `app/window-classify.js`，黑名单 56 → 129 项并加 `overlay/launcher` 正则，NVIDIA Overlay、启动器等不再被当成游戏 |
| 菜单不被隐藏 | 「切出游戏时隐藏歌词」在面板/拖动模式下不再生效 |

**自助排查**：若某个程序仍被误认为游戏（歌词贴到它上面），到「窗口」页的排除列表里填它的进程名
（如 `NVIDIA Overlay`、`WeGame`），逗号分隔，立即生效。

## 八、已知限制（不粉饰）

1. **独占全屏不可见**：任何普通置顶窗都会被独占全屏游戏盖住，需把游戏改成「无边框窗口化」。
2. **反作弊自判**：程序不注入进程、不读内存、不模拟按键，但带反作弊的联机游戏是否允许覆盖层由用户自行判断。
3. **汽水 / Apple Music / Spotify 无官方歌词接口**：用同曲匹配，冷门曲可能只有整行 LRC 或匹配不到。
4. **Wayland 无窗口跟随**：系统不提供跨客户端窗口几何，自动退回整屏覆盖。
5. **macOS 未签名未公证**：首次打开需右键「打开」，并授予「辅助功能」+「自动化」权限。
6. **macOS / Linux 缺真机交互验证**：目前证据等级是「契约测试 19 项 + CI 构建 + Linux 上跑通 107 项 UI 回归」。
7. **Spotify 搜索需自备凭据**：`developer.spotify.com` 免费创建 app，填进「通用」页，只存本机。
