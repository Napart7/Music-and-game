# 平台适配说明

> 适用版本：v1.0.0 · 最后更新：2026-11-15

这份文档说明 GlassLyrics 对 **QQ 音乐、网易云音乐、酷狗音乐、汽水音乐、Apple Music、Spotify** 六个播放器的适配方式、能力边界与已知限制。所有能力均基于**公开接口**与 **Windows 系统媒体接口（SMTC）**，不注入播放器进程、不抓取音频、不破解加密歌词。

## 二、统一接入层：Windows SMTC

所有平台的「正在播放」信息都来自 Windows 自带的 `GlobalSystemMediaTransportControlsSessionManager`（主菜单显示的平台就是这么识别的）：

```
播放器客户端 → 注册系统媒体会话（SMTC）→ GlassLyrics 读取
   ↑                                        ↓
   └──────── 播放/暂停/切歌指令 ←───────────┘
```

- **为什么这样做**：不需要每个平台各写一套 SDK，不需要账号，不会因为平台改版失效；对游戏来说只是系统级媒体控制，和耳机上的播放键等价。
- **进程识别表**（用于判断当前平台、决定歌词源优先级）：

| 平台 | 识别的进程 / 应用标识（不区分大小写） |
|---|---|
| QQ 音乐 | `QQMusic.exe`、`Tencent.*Music` |
| 网易云音乐 | `cloudmusic.exe`、`NeteaseCloudMusic`、`music.163.com` |
| 酷狗音乐 | `KuGou.exe`、`KGMusic`、`KuGouConcept`（概念版） |
| 汽水音乐 | `QishuiMusic.exe`、`LunaMusic`、`SodaMusic` |
| Apple Music | `AppleMusic.exe`、`AppleInc.*Music`、`Music.UI` |
| Spotify | `Spotify.exe` |

> 客户端必须在设置里打开「系统媒体控制 / 显示当前播放」。QQ 音乐路径：设置 → 常规设置 → 通知 → 显示系统媒体传输控制。Apple Music 与 Spotify 的 Windows 客户端默认开启。

## 三、各平台详解

### 1. QQ 音乐

| 项目 | 说明 |
|---|---|
| 歌词来源 | `c.y.qq.com` 搜索 + `fcg_query_lyric_new` 歌词接口（LRC + 翻译） |
| 逐字 | 平台只提供整行 LRC，程序按行时长推算字时间（界面标注「逐字为推算」） |
| 选歌 | 公开搜索接口，15 条/页 |
| 唤起播放 | `qqmusic://qq.com/ui/search?w=歌名` |
| 已知限制 | QRC 逐字格式加密，需登录态解密，**未做**（不硬凑） |

### 2. 网易云音乐

| 项目 | 说明 |
|---|---|
| 歌词来源 | `music.163.com/api/song/lyric/v1`（`yv=1` 返回 **YRC 逐字**）+ 翻译 `ytlrc` |
| 逐字 | ✅ 唯一提供**真实逐字时间轴**的平台 |
| 选歌 | 公开搜索接口，15 条/页 |
| 唤起播放 | `orpheus://search?q=歌名` |
| 已知限制 | 部分版权曲缺失；接口偶尔限流，自动降级到其它源 |

### 3. 酷狗音乐

| 项目 | 说明 |
|---|---|
| 歌词来源 | `mobiles.kugou.com` 搜索 → `krcs.kugou.com` 候选 → `lyrics.kugou.com/download?fmt=lrc`（**明文 LRC**） |
| 逐字 | 平台 LRC 为整行，程序推算字时间 |
| 选歌 | 公开搜索接口，15 条/页，带封面 |
| 唤起播放 | `kugou://歌名` |
| 封面 | `imge.kugou.com/stdmusic/480/<album_id>.jpg` |
| 已知限制 | KRC 逐字格式加密（XXTEA），**不做解密**；概念版部分接口不同 |

### 4. 汽水音乐（抖音）

| 项目 | 说明 |
|---|---|
| 歌词来源 | 🟡 **同曲匹配**：以曲名 + 歌手在网易云 → QQ → 酷狗 → LRCLIB 找同一首歌 |
| 逐字 | 推算 |
| 选歌 | 🟡 经网易云曲库匹配（汽水无公开搜索接口） |
| 唤起播放 | ⬜ 无稳定公开 URL Scheme，点「去播放」只复制歌名到剪贴板 |
| 已知限制 | 汽水的 luna 接口需要设备签名，未做逆向；会员曲可能只在客户端内可播 |

### 5. Apple Music

| 项目 | 说明 |
|---|---|
| 歌词来源 | 🟡 同曲匹配（LRCLIB → 网易云 → 酷狗）；Apple 无公开歌词接口（MusicKit 需要付费开发者 + 用户授权） |
| 元数据 / 封面 | ✅ **iTunes Search API**（公开免认证），600×600 封面 |
| 选歌 | ✅ iTunes 目录搜索，15 条/页 |
| 唤起播放 | `music://music.apple.com/search?term=歌名` |
| 已知限制 | 国区 Apple Music 曲库少，iTunes 搜索结果可能与客户端版本不同（live/remaster 差异） |

### 6. Spotify

| 项目 | 说明 |
|---|---|
| 播放控制 | ✅ 走 SMTC（客户端自带系统媒体控制） |
| 歌词来源 | 🟡 同曲匹配（LRCLIB 优先，英文歌覆盖最好） |
| 元数据 / 封面 | ✅ **Spotify Web API**（需自备 Client ID / Secret） |
| 选歌 | ✅ Spotify 曲库搜索 10 条/页（2026 年起开发者模式上限） |
| 认证 | **Client Credentials**（应用级，不登录你的账号、不读私人歌单）。凭据只存本机 `config.json` |
| 唤起播放 | `spotify:search:歌名` |
| 已知限制 | 不内置任何凭据（合规要求，且共享密钥会被封）；歌词非官方；搜索需要你免费申请一个开发者 App |

**申请 Spotify 凭据（30 秒）**：
1. 打开 https://developer.spotify.com/dashboard → 登录 → **Create app**
2. 名称随意，Redirect URI 填 `http://127.0.0.1:8888/callback`
3. 复制 **Client ID** 与 **Client Secret** → 粘贴到 GlassLyrics「通用 → Spotify 开发者凭据」→ 保存

## 四、平台差异与兼容性处理

| 差异 | 处理方式 |
|---|---|
| 只有网易云给逐字，其余给整行 | 统一转换为内部 `lines[{time,text,words?}]` 结构；无逐字时按字宽/标点推算，UI 明确标注「推算」，不冒充真逐字 |
| 有的平台没有歌词接口 | 统一的**同曲匹配链**：按平台决定优先级（见 `resolveOrder`），逐级降级，结果本地缓存 |
| 有的平台没有封面 | iTunes Search 补封面（Spotify / Apple / 汽水）；失败则显示占位符 |
| 歌词头部有「作词/作曲/制作人」 | 统一的制作信息过滤器（正则 + 时间窗 + 纯 ASCII 行判定），三个平台共用 |
| 翻译字段各不相同 | QQ 的 `trans`、网易云的 `ytlrc/tlyric` 统一挂到行的 `tr` 字段，右侧栏显示 |
| URL Scheme 各不相同 | 每个平台独立映射；没有稳定 Scheme 的（汽水）只复制歌名，绝不假装成功 |
| 进程名写法五花八门 | 统一正则匹配，新增平台只需在 `platformFromApp` 加一条规则 |
| 平台接口限流/失效 | 每个请求 12 秒超时 + 逐级降级 + 本地缓存（上限 300 条，自动修剪最旧） |

## 五、能力边界（明确不做）

- ❌ 不注入游戏或播放器进程、不读内存、不挂钩子
- ❌ 不抓取音频流、不下载歌曲、不破解 DRM
- ❌ 不破解 KRC / QRC 等加密逐字格式
- ❌ 不内置任何第三方平台凭据；Spotify 凭据由用户自备，仅存本机
- ❌ 不模拟全局按键控制播放器（走 SMTC，游戏内不会抢键）
- ⚠️ 带反作弊的联机游戏请自行判断是否使用覆盖层

## 六、故障排查

| 现象 | 检查 |
|---|---|
| 平台显示「其它播放器」 | 客户端是否注册了系统媒体控制；是否用的是网页版（网页版浏览器才有 SMTC，且平台识别为浏览器） |
| 歌词显示「未找到」 | 换「歌词源」为自动；点刷新；冷门歌可能四个源都没有 |
| Spotify 搜索提示需要凭据 | 按上文申请并填入「通用」页 |
| 汽水 / Apple 歌词不是官方 | 正常，这两个平台无公开歌词接口，用同曲匹配 |
| 酷狗有歌但没歌词 | 该曲无公开 LRC（纯音乐/KRC-only），可切歌词源到网易云重试 |
