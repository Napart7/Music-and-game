## GlassLyrics v1.3.0 — 连接快 · 显示流畅 · 操作丝滑

本轮以**用户真实观感**为准做性能攻坚，全部改动都有基准数据支撑。完整报告见 [docs/性能自检-v1.3.md](https://github.com/Napart7/Music-and-game/blob/main/docs/性能自检-v1.3.md)。

### 连接速度

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 切歌出歌词（auto，网易云 YRC） | 1810ms | **221ms（-88%）** |
| 冷启新歌（打包版实测） | — | **303ms / 60 行真逐字** |
| 热缓存（听过的歌） | 1ms | **0-1ms** |
| 英文歌 LRCLIB 不可达 | 14.7s | 7.5s 首拉，之后 2.5s |
| 切歌瞬间反馈 | 无 | **立即显示「正在加载歌词…（歌名）」** |

关键改动：
- **并行竞速**：所有歌词源同时请求，谁先给真逐字就用谁，不再"QQ 等 1.7s 再网易云"
- 超时 12s→6s（LRCLIB 5s）+ 连续失败后 10 分钟快速探测
- 启动预热 QQ / 网易云 / 酷狗 / iTunes 的 DNS+TLS

### 流畅度（每场景 2 秒采样）

| 场景 | 优化前 | 优化后 |
|---|---|---|
| 主菜单打开（毛玻璃） | 53fps · **13.2% 掉帧** | **60fps · 0% 掉帧** |
| 144Hz 屏动画 | ~48fps（门槛算法） | **稳定 60fps** |
| 拖动歌词（125Hz 鼠标） | 125 次样式写/秒 | rAF 合并 → 60 次/秒 |
| 其余 6 个场景 | 60fps | **60fps，p95 16.7ms** |

关键改动：
- 菜单打开时暂停歌词动画 + 歌词层 `visibility:hidden`（原来 `opacity:.12` **仍在绘制满屏阴影**）
- 时间预算累积器替代固定 dt 门槛，高刷屏帧间隔均匀
- 拖动用 rAF 合并

### 体验细节
- 切歌 → 状态栏立即显示加载中（不再"像没反应"）
- 日志输出每次歌词耗时 `[lyrics] 网易云音乐 · netease-yrc · 60 lines · 303ms`，问题可定位

### 验证
- 帧时间基准 7 场景：全部 60fps、p95 16.7ms、0% 掉帧
- 回归 **181 项全绿**；打包版冒烟：`packaged:true / 303ms / 60 行 YRC / clickThrough:true`
- CI 三平台（Windows / macOS / Linux）+ Linux UI 回归
