## GlassLyrics v0.9.1 — 修复「切屏回来点不动游戏」

### 修复
**症状**：Alt-Tab 切出游戏再回来，鼠标点不动游戏，像被什么挡住了。

**根因**：覆盖层是一整块全屏透明窗口，"能不能点"是窗口级的。主菜单或「自由拖动歌词位置」只要没被正确关闭，整个屏幕的点击都会被这一层吞掉——这是旧版把"可点击"状态留在那儿造成的。

**四重保险（全部新增）**：
1. **失焦自动收起** — 切到别的窗口（Alt-Tab / 点任务栏）时，菜单与拖动模式立即关闭并恢复穿透；
2. **点面板外立即收起** — 菜单开着时点面板外任意位置，菜单马上关，第二下点击就落到游戏；
3. **拖动模式点空白 / Esc 立即退出** — 不会再有"拖动模式残留"；
4. **2 秒心跳核对穿透状态** — Windows/Electron 在焦点切换后可能悄悄丢掉穿透标志，程序会周期性重申，自动恢复。

另外把窗口显示、状态切换全部收敛到一个统一的状态机，清掉了会绕过状态的旧接口。

### 验证
- 回归 154 项全绿（新增 3 项：点面板外收起菜单 / 点空白退出拖动 / 点歌词不误退出）
- 实机冒烟：`clickThrough:true, panelOpen:false, editMode:false`；模拟卡住 UI 后面板自动收起、穿透恢复
- 开发版 + 打包版均验证
