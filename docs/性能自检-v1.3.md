# v1.3.0 性能与体验自检报告（用户视角）

> 检查时间：2026-11-15 · 方法：三套可复现基准 + 打包版冒烟
> 目标：连接快、显示流畅、操作丝滑

---

## 一、检查方法

| 基准 | 工具 | 测什么 |
|---|---|---|
| 帧时间分布 | `tools/bench_perf.mjs`（headless Chromium + CDP） | 7 个真实场景各采样 2s：平均帧、p95、最大帧、>25ms 掉帧占比 |
| 连接延迟 | `tools/bench_lyrics.mjs`（真实网络） | 冷缓存首拉、热缓存、auto 串行/并行、各源单独耗时 |
| 端到端 | 打包版冒烟（GL_SMOKE） | 从 SMTC 曲目到歌词进 DOM 的真实耗时（`elapsedMs`） |

> 帧率测试跑在**软件光栅**的无头浏览器里，比真实 GPU 更苛刻；这里能达到 60fps，实机只会更好。

---

## 二、发现的问题与修复

### P0 — 歌词连接慢（用户最直接的"卡"）

| # | 现象（用户视角） | 根因 | 修复 | 前后对比 |
|---|---|---|---|---|
| 1 | 切歌后要等 2 秒才出歌词 | auto 模式**串行**：QQ 先跑 1.7s，拿到整行 LRC 后仍继续等网易云 YRC | **并行竞速**：所有源同时发，谁先给真逐字立即采用；给整行歌词 900ms 窗口 | **1810ms → 221ms（-88%）** |
| 2 | 英文歌（Spotify/Apple）要等十几秒 | `lrclib.net` 在国内常不可达，单请求超时 12s | 超时 12s→**6s**（LRCLIB 5s）；连续失败 2 次后 10 分钟内只探测 2.5s | **14.7s → 7.5s 首拉，之后 2.5s** |
| 3 | 每次新歌都慢一点 | 每个请求都要重新 DNS+TLS 握手 | 启动 2.5s 后**预热** QQ/网易云/酷狗/iTunes 四个域名 | 首拉省去 ~200-400ms 建连 |
| 4 | 切歌瞬间"像没反应" | 旧歌词还挂在屏幕上，没有任何反馈 | 新增 `lyrics-loading` 事件 → 状态栏显示「正在加载歌词…（歌名）」 | 感知延迟≈0（立即有反馈） |
| 5 | 选歌页偶发"搜索失败"等很久 | 全局 12s 超时 | 6s 快速失败 + 逐级降级 | 失败反馈更快 |

**实测（打包版，冷缓存新歌《夜曲》）**：

```
[lyrics] 网易云音乐 · netease-yrc · 60 lines · wordSync=true · 303ms
```

### P1 — 掉帧（显示不流畅）

| # | 现象 | 根因 | 修复 | 前后 |
|---|---|---|---|---|
| 6 | 打开主菜单时明显一顿 | 面板 `backdrop-filter` 与满屏歌词的 8 层 text-shadow 争 GPU；且歌词层只是 `opacity:.12`，**仍在绘制** | ① 菜单打开时暂停歌词动画 ② 歌词层 `visibility:hidden`（跳过整层绘制） | **53fps / 13.2% 掉帧 → 60fps / 0%** |
| 7 | 144Hz 屏幕上动画不够顺 | 固定 `dt<16.4ms` 门槛在 144Hz 上每 3 帧才放行一次（≈48fps） | **时间预算累积器**：余数累计，平均稳定 60（低配 30） | 48fps → 60fps，帧间隔均匀 |
| 8 | 拖动歌词时鼠标发飘 | 125Hz 鼠标每次移动都写 CSS 变量 | mousemove → **rAF 合并**，每帧最多写一次 | 写入频率 125/s → 60/s |

### P2 — 其他（前几版已修，本轮复核）

- 覆盖层隐藏时帧循环彻底停止
- 暂停/静止时零样式写入
- `renderGlyphs` 缓存元素引用，无逐帧查找
- 切句重建压力测试（6.7 次/秒，是真实歌曲的 30 倍）仍 60fps

## 六、剩余瓶颈（诚实说明）

1. **QQ 音乐搜索接口本身慢**（0.8-1.7s 波动）：非本地可优化，已通过"并行 + 不阻塞"规避——QQ 慢不会再拖累网易云结果。
2. **LRCLIB 国内不可达**：只能缩短等待与探测，无法变快；英文歌的歌词质量仍以 LRCLIB 为最佳，但用户最多等 5s（首拉）。
3. **SMTC 轮询 500ms**：切歌感知存在 ≤500ms 固有延迟（系统接口无事件订阅能力）。已用"立即显示加载中"把感知延迟降到接近 0。
4. **无真机 GPU 数据**：本轮为软件光栅基准 + Windows 打包版冒烟，未在低端核显实机采样；如需可加 `GL_PERF_LOG=1` 现场采集。

## 七、复现命令

```bash
node tools/bench_perf.mjs     # 帧时间分布（7 场景）

GL_SMOKE=1 GL_FORCE_LYRIC_SOURCE=netease GL_FORCE_TRACK="夜曲|周杰伦|226" npx electron .
```
