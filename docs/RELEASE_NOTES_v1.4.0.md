# GlassLyrics v1.4.0 · 歌词跟得上耳朵，仓库讲得清自己

> 这版没有大改渲染管线，只解决两件每天都在发生的小烦：**歌词和声音差半拍**，以及
> **别人（和三个月后的你）打开仓库看不懂它能干什么**。

---

## ✨ 新功能

### 1. 歌词偏移微调热键

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + PageUp` | 歌词提前 0.1 秒 |
| `Ctrl + Alt + PageDown` | 歌词延后 0.1 秒 |

- 步进 100ms，范围 ±3000ms，连按累积；**全局生效**，游戏里直接按，不用开菜单
- 与「视觉」页的时间轴滑块是同一份配置，两边永远同步
- 可在「通用 → 全局热键」重绑定；被其它软件占用会标「占用」
- 典型用途：蓝牙耳机（常见 100–300ms 延迟）按 1–3 次 `PageUp`；HDMI 接电视补帧延迟同理

### 2. 屏幕轻提示（Toast）

热键调偏移时，屏幕下方浮出 1.7 秒的胶囊提示：

```
        歌词偏移 +200 ms（更早）
```

- 点击穿透、不挡操作，毛玻璃质感与主菜单一致
- 菜单打开时自动隐藏（那块区域正好被面板盖住）
- 只用一条 CSS 过渡，不新增任何动画循环；暂停/隐藏时依旧零开销

### 3. 关于页说真话

- 版本号 / 运行平台 / 架构 / Electron 版本全部改为**运行时读取**（之前硬编码 `1.0.0`）
- 新增「最近更新」卡片，显示最近 3 个版本要点，不用去 GitHub 翻
- 技术栈文案修正为「Electron + 系统媒体接口（SMTC / AppleScript / MPRIS）」

### 4. 应用内更新日志不断线

```
CHANGELOG.md ──(tools/gen_changelog.mjs)──▶ app/changelog.json ──▶ 关于页
      ↑                                            ↑
   唯一手写源                                随安装包发布；门禁校验一致
```

改日志只改 `CHANGELOG.md`，忘了生成会被 `check_compliance.mjs` 拦下。

## ⚠️ 已知问题

- 本机实测 `Ctrl+Alt+F`（开关窗口自适应）被其它软件占用，注册失败。遇到请到「通用」页重绑
  （例如 `Ctrl+Alt+G`），托盘菜单也能切这个开关。
- 其余限制与上一版一致：独占全屏不可见、Wayland 无窗口跟随、macOS 未签名、
  汽水/Apple/Spotify 用同曲匹配歌词、Spotify 搜索需自备凭据。

## 升级方式

- **Windows**：`GlassLyrics Setup 1.4.0.exe`（覆盖安装，配置保留）或 `GlassLyrics-Portable.exe`
- **macOS**：`GlassLyrics-1.4.0-arm64.dmg` / `-1.4.0.dmg`（首次右键「打开」）
- **Linux**：`GlassLyrics-1.4.0.AppImage` 或 `glasslyrics_1.4.0_amd64.deb`

从 0.9.0 之前版本升级的，务必升到 1.4.0（0.9.0 存在切屏回来吞点击的缺陷）。
