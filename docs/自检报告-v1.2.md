## 二、发现并修复的问题（14 项）

### P1 — 功能性缺陷

| # | 问题 | 根因 | 修复 | 验证 |
|---|---|---|---|---|
| 1 | **macOS / Linux 封面永远不显示** | 归一器输出字段是 `cover`，渲染层却读 `d.coverUrl` | 渲染层改读 `d.cover`，并做同值去重 | 新增契约测试「coverUrl 归一为 cover」 |
| 2 | **macOS 媒体链路可能完全收不到数据** | JXA 的 `console.log` 不保证写入 stdout（部分系统走 stderr） | 改为 `NSFileHandle.fileHandleWithStandardOutput.writeData` 显式写，保留 console 兜底 | JXA 语法检查 + 契约测试样本 |
| 3 | **未知播放状态被当成"正在播放"** | `normalizeMedia` 只排除 NONE/CLOSED | 改为白名单：未知状态 → `UNKNOWN` + `active:false` + `statusValue:-1` | 新增断言「未知状态不会被当成播放中」 |

### P2 — 稳定性与性能

| # | 问题 | 根因 | 修复 | 效果 |
|---|---|---|---|---|
| 4 | **Linux 无 AppIndicator 时托盘创建抛错 → 主进程崩溃** | `new Tray()` 未包 try/catch | 捕获后 `tray=null`，覆盖层继续工作（热键仍可唤出菜单） | 容错路径 |
| 5 | **Linux 窗口探针进程风暴** | 每 400ms 起 3×xprop + sed/awk/tr 共 ~11 个进程 | 一次 xprop 读 4 属性 + 纯 bash 解析 + bash 内建转义 | **27 进程/秒 → 7.5 进程/秒（-72%）** |
| 6 | **覆盖层隐藏后 rAF 仍满帧空转** | `backgroundThrottling:false` + 无可见性判断 | tick 首行判断 `layerVisible`，隐藏即 return（rAF 保留调度） | 隐藏时 CPU 归零，恢复无跳帧 |
| 7 | **启动时 `show:false` 导致 rAF 被挂起**（自检中引入又发现） | Chromium 判定窗口被遮挡 → 暂停 rAF，歌词时间轴冻结 | 回滚为启动可见（`focusable:false` 已保证不抢游戏焦点），保留 `showInactive` 供隐藏后恢复 | 冒烟 frames 3 → 130 |
| 8 | **后端脚本崩溃时无限快速重启** | 固定 1.5s 重启 | 指数退避 1.5s→3s→6s→12s（上限 15s），收到数据即重置 | 防日志风暴/CPU 打满 |
| 9 | **同一后端错误每 400/500ms 刷日志** | 无去重 | `lastBackendError` / `lastProbeError` 记忆，仅打印一次 | 日志干净 |
| 10 | **auto-fit 每 400ms 无条件广播 + 渲染层反复写样式** | 状态未变也发送 | 主进程比较 JSON 后再发；渲染层 `--ui-scale` / `--game-w/h` / compact / 文本均加变化检测 | 静止时 0 次 IPC / 0 次样式写 |

### P3 — 质量与一致性

| # | 问题 | 修复 |
|---|---|---|
| 11 | mac 每 tick 6 次属性 AppleEvent | 改 `track.properties()` 一次批量读取，失败回退逐项（约 6 → 2 次） |
| 12 | `applyTrack` 每 500ms 写 8 个 DOM 节点 | 统一 `setText()` 变化检测；进度条宽度同样判断 |
| 13 | Linux Java 游戏缺 `_NET_WM_NAME` → 标题为空 | xprop 同一次调用加 `WM_NAME` 兜底 |
| 14 | Spotify 401/403 只显示"搜索失败" | 映射为「凭据无效」提示，引导重新填写 |

### 附带清理

- 删除 `media-linux.sh` 中未被调用的 `to_seconds()`；移除 playerctl 不支持的 `{{status}}` 字段
- `--game-w/--game-h` 从 scale 分支中拆出，窗口尺寸变化即更新
- `config.json` 若含 Spotify secret，POSIX 下 `chmod 0600`
- 启动窗口改 `showInactive` 语义（保留可见性），恢复显示不抢游戏焦点

## 七、剩余风险与未覆盖项

1. **macOS / Linux 尚无真机交互验证**：仅有契约测试 + CI 构建 + Linux 渲染回归。首次真机使用若异常，请附控制台日志。
2. **Wayland**：系统级限制，窗口跟随不可用（已优雅降级）。
3. **macOS 全屏游戏层级**：Metal 独占全屏可能盖住置顶窗，建议无边框窗口。
4. **KRC / QRC 逐字**：仍为加密格式，未破解（合规选择）。
5. **Spotify 搜索**：需用户自备开发者凭据，属平台要求。
6. **反作弊**：覆盖层本身不注入，但联机游戏使用风险自负。
