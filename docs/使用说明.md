# GlassLyrics 使用说明（v0.6 正式版）

> 当前版本：**正式可用**。QQ 音乐 / 网易云音乐双平台歌词、网易云 YRC 真实逐字、液态玻璃主菜单、字形发散辉光（无方框）、自捕捉游戏窗口自适应都已实现。

## 一、安装

**方式 A：一键安装包（推荐）**
1. 去 GitHub Releases 下载 `GlassLyrics Setup 0.1.0.exe`
2. 双击，一路「下一步」
3. 桌面出现图标，双击启动

**方式 B：绿色便携版**
1. 下载 `GlassLyrics-Portable.exe`
2. 放到任意文件夹，双击即用，不写注册表（除开机自启开关）

**方式 C：源码运行**
```bash
cd app
npm install
npm start
```
从 WorkBuddy 等 Electron 应用内启动要加 `env -u ELECTRON_RUN_AS_NODE npm start`。

**要求**：Windows 10/11（自带 PowerShell 5.1）、QQ 音乐 ≥ 21.10.2962 或网易云音乐 3.x。**不需要装 WebView2**，Electron 自带 Chromium。首次拉歌词需要能访问 `c.y.qq.com` / `music.163.com` / `lrclib.net`。

## 二、第一次配置（只做一次）

1. **打开 QQ 音乐的 SMTC 开关**：`设置 → 常规设置 → 通知 → 显示系统媒体传输控制 (SMTC)`。
2. 放一首歌，确认 Windows 音量面板 / 任务栏能看到歌名和进度。
3. 启动 GlassLyrics，屏幕左右两侧应出现逐字歌词。
4. **把游戏改成「无边框全屏」或「窗口化」**。独占全屏会盖住所有覆盖层，这是 Windows 显示规则，不是程序故障。
5. 按 `Ctrl+Alt+P` 打开主菜单，确认「歌词」页能看到歌词来源和逐字精度。

> 画面上**没有任何状态胶囊**。想查看当前平台、歌词源、跟随状态，主动打开主菜单即可。

## 三、游戏里怎么用

| 操作 | 效果 |
|---|---|
| 默认 | 只显示歌词，**鼠标完全穿透**，不挡任何游戏操作 |
| `Ctrl + Alt + P` | 打开 / 收起**液态玻璃主菜单**（打开时可点，收起后恢复穿透） |
| `Ctrl + Alt + H` | 显示 / 隐藏整个覆盖层 |
| `Ctrl + Alt + B` | 循环切换布局：双侧 → 居中 → 仅左 → 仅右 |
| `Ctrl + Alt + F` | 开 / 关自动捕捉游戏窗口（被占用时回退 `Ctrl+Shift+Alt+F`） |
| `Ctrl + Alt + Q` | 退出（被占用时自动回退 `Ctrl+Shift+Alt+Q`） |
| `Esc` | 收起主菜单 |
| 托盘图标右键 | 显隐、主菜单、**歌词源子菜单**、自动捕捉、切出隐藏、开机自启、退出 |

播放控制通过系统 SMTC 发给音乐客户端，不模拟全局按键，不影响游戏输入。

> 主菜单打开期间整层窗口会临时停止穿透，这是 Electron 单窗口的已知取舍。操作完按一次 `Ctrl+Alt+P` 或 `Esc` 收起即可恢复。

## 四、主菜单

`Ctrl+Alt+P` 唤出。液态玻璃观感按 DangoMusic 的 `ui/glass.frag` 规格做 CSS 近似：SDF 圆角、边缘折射、RGB 色散、左上主光。

| 分区 | 能做什么 |
|---|---|
| **播放** | 看曲名 / 艺人 / 专辑 / 进度 / 播放器平台 / 歌词源 / 逐字精度；⏮ ⏯ ⏭ 控制播放 |
| **歌词** | 选歌词源优先级（自动 / QQ 音乐 / 网易云 / LRCLIB / 关闭）；调时间轴偏移滑块；刷新歌词；翻译开关；查看窗口跟随状态 |
| **视觉** | 辉光四色（白 / 粉 / 蓝 / 琥珀）、辉光强度、发散半径、歌词字号；逐字弹跳 / 字摆动 / 整句砸入 / 黑描边；4 种布局 |
| **窗口** | 自动捕捉游戏窗口、切出游戏时隐藏、排除进程名单（逗号分隔） |
| **通用** | 开机自启、显示器序号、热键说明、退出程序 |
| **关于** | 版本、技术栈、隐私与安全声明 |

菜单打开时两侧歌词会自动淡出，避免和菜单重叠；收起后恢复。

## 五、歌词源与平台适配

程序通过 SMTC 的 `SourceAppUserModelId` 自动认出当前播放器，默认按这个顺序找歌词：

| 当前播放器 | 尝试顺序 |
|---|---|
| QQ 音乐 | QQ 音乐 → 网易云 → LRCLIB |
| 网易云音乐 | 网易云 → QQ 音乐 → LRCLIB |
| 其它 | LRCLIB → 网易云 → QQ 音乐 |

**质量优先**：`自动` 模式下，即使 QQ 音乐先返回了整行 LRC，程序也会继续试网易云；只要拿到 **YRC 真实逐字**就立刻采用。实测《孤勇者》在 QQ 音乐播放时也会升级到网易云 YRC 52 行真逐字。手动在主菜单或托盘锁定某个源时立即返回，尊重你的选择。

| 源 | 拿到什么 | 逐字精度 |
|---|---|---|
| 网易云音乐 | `/api/song/lyric/v1?level=ex&yv=1` 的 YRC（`[行开始,时长](字开始,字时长,0)字…`） | **真实逐字**，按播放进度精确点亮 |
| QQ 音乐 | `fcg_query_lyric_new.fcg` 的 LRC + 翻译 | 整行时间轴，逐字按行时长推算 |
| LRCLIB | 社区整行 LRC | 整行时间轴，逐字按行时长推算 |

主菜单「歌词」页会明确写出当前是「YRC 真实逐字」还是「按行时长推算」，不会把推算冒充成真逐字。制作信息（作词 / 作曲 / 版权 / `Vocal edite` / 标题行）自动过滤，翻译按时间戳就近挂载。

结果缓存在 `%APPDATA%\glasslyrics\lyrics-cache\`，带版本号；策略升级后自动重拉一次。点「刷新歌词」可强制重新拉取。

> 只请求**公开文本接口**，不登录、不保存账号 / `MUSIC_U` / Cookie。发给网易云的 `appver=3.1.39; os=pc` 只是公开客户端版本标识（让接口返回 `yrc`），不是凭证。仓库与安装包不含任何歌词文本。

## 六、辉光与布局

辉光由**每个字自身的四层 `text-shadow`** 沿笔画向外发散，逐字扫光用柔边渐变遮罩——**没有矩形发光底板**，也不会出现直角方框。视觉参数在主菜单「视觉」页实时可调：

| 参数 | 默认值 | 作用 |
|---|---|---|
| 辉光色 | 白 | 白 / 粉 / 蓝 / 琥珀，对应 jar 的 `glowTint` |
| 辉光强度 | 0.30 | 对应 `glowStrength`，调高光更亮 |
| 发散半径 | 0.50 | 对应 `glowRadius`，调高光散得更远 |
| 歌词字号 | 1.00 | 0.75–1.4 |
| 逐字弹跳 / 字摆动 / 整句砸入 / 黑描边 | 开 | 对应 `wordPop` / `wiggle` 8fps / `textFlash.popScale` / `drawGlyph` |

歌词默认在屏幕**垂直中部的左右两侧**：左边原文逐字，右边翻译 / 下一句，**正中间约 30% 宽度完全空着**。可切「双侧 / 居中 / 仅左 / 仅右」。

## 七、自捕捉游戏窗口与自适应（默认开）

程序每 400ms 看一次前台窗口，认出游戏后覆盖层**贴到游戏窗口的矩形上**：

- 游戏窗口移动、缩放、切换显示器 → 歌词跟着走
- 窗口变小 → 自动进紧凑模式，收窄侧栏、缩小字号，**中央视野始终留空**
- **打开主菜单时**自己的窗口成为前台，程序会保持已捕捉的矩形，不会跳回整屏
- 切到桌面或别的软件 → 默认退回整屏并淡出；勾选「切出游戏时隐藏」则直接隐藏
- 不跟随小于 640×400 的窗口，避免把小弹窗当游戏

想关掉按 `Ctrl+Alt+F`，或在主菜单「窗口」页取消勾选。想跳过某些程序，在「窗口」页的排除名单里填进程名（默认空）。

> 自捕捉**只读窗口位置和大小**，不打开游戏进程、不读内存、不注入。安全边界在这里，不在"不显示"。

## 八、设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 开机自启 | **关** | 主菜单「通用」页或托盘控制，不强制、不偷偷加 |
| 自动捕捉游戏窗口 | **开** | 热键 / 主菜单 / 托盘均可切换 |
| 切出游戏时隐藏 | **关** | 开：切到非游戏窗口直接隐藏；关：退回整屏并淡出 |
| 排除进程 | 空 | 主菜单「窗口」页填，默认不排除任何游戏 |
| 歌词源 | auto | `auto` / `qqmusic` / `netease` / `lrclib` / `off`（关闭在线歌词） |
| 时间轴偏移 | 0 ms | 主菜单「歌词」页滑块，正数歌词提前、负数延后 |
| 显示翻译 | 开 | 平台提供翻译时显示在右栏 |
| 辉光色 / 强度 / 半径 / 字号 | 白 / .30 / .50 / 1.00 | 主菜单「视觉」页 |
| 歌词布局 | **双侧不挡视野** | 可切居中 / 仅左 / 仅右，自动保存 |
| 显示器 | 主屏 | 主菜单「通用」页；自适应时自动选游戏所在屏 |
| 全局热键 | 见下表 | 全部可在「通用」页点击按钮重新绑定，被占用会标记 |
| 歌词位置 | 默认两侧居中 | 「视觉」页进入拖动模式自由摆放，松手保存，重启保留 |
| 侧栏宽 / 行距 / 字重 / 不透明度 | 28vw / 1.5 / 600 / 1.0 | 「视觉」页滑块实时生效 |
| 配置文件 | `%APPDATA%\glasslyrics\config.json` | 纯本地，不上传 |

**默认热键**（都可改）：

| 动作 | 默认 |
|---|---|
| 打开 / 收起主菜单 | Ctrl + Alt + P |
| 显示 / 隐藏覆盖层 | Ctrl + Alt + H |
| 切换歌词布局 | Ctrl + Alt + B |
| 开关窗口自适应 | Ctrl + Alt + F |
| 退出程序 | Ctrl + Shift + Alt + Q |
| 上一首 / 下一首 / 播放暂停 | 未设置（避免抢游戏按键，需要再设） |

**改热键**：主菜单「通用」页 → 点某个动作右边的按钮 → 按新组合键（必须带 Ctrl/Alt/Shift 之一，或用 F1–F24）→ 松手即生效。Esc 取消，Delete 清空。提示「占用」说明被别的软件占了，换一个组合。

**拖动歌词位置**：主菜单「视觉」页 → 「自由拖动歌词位置」→ 菜单自动收起，两侧歌词出现虚线框 → 直接用鼠标把左/右歌词拖到任何位置（上下、贴边都行）→ 松手自动保存 → 点顶部条的「完成」退出。点「重置位置」恢复默认。

**搜索选歌（换平台歌单）**：主菜单「选歌」页 → 切换 QQ 音乐 / 网易云 → 输入歌名或歌手 → 搜索 → 点「去播放」。程序会尝试唤起对应客户端的搜索页，同时把歌名复制到剪贴板；客户端没反应就在播放器里粘贴搜索一下，播放后歌词自动跟上。

## 九、常见问题

**Q：歌词没跟着游戏窗口走 / 跑到窗口外了？**
打开主菜单「歌词」页看「窗口自适应」那一行：显示「宽×高 跟随中」说明已贴合；显示 `non-game-app` 说明前台被判成非游戏（或窗口小于 640×400）。把游戏切到前台，或按 `Ctrl+Alt+F` 关掉再开。独占全屏仍无法覆盖，改「无边框全屏」。

**Q：游戏里看不到歌词？**
99% 是独占全屏。另外确认音乐客户端正在播放、SMTC 开关已开、主菜单「歌词」页显示歌词来源而不是「未找到歌词」。

**Q：中文歌没歌词？**
现在有 QQ 音乐和网易云两个中文源，覆盖率比只靠 LRCLIB 时高得多。都查不到会回退到原创演示占位句，不会显示错歌词。点「刷新歌词」可强制重拉。

**Q：歌词快了 / 慢了？**
主菜单「歌词」页拖「整体偏移」滑块，或改配置里的 `lyricOffsetMs`（毫秒，正数=歌词提前，负数=延后）。

**Q：歌词是逐字的吗？**
看主菜单「播放」页的「逐字精度」：`YRC 真实逐字` 表示与播放进度严格同步（目前网易云提供）；`按行时长推算` 表示视觉近似（QQ 音乐 / LRCLIB）。程序不会把推算冒充成真逐字。

**Q：为什么我在 QQ 音乐放歌，歌词来源却显示网易云？**
这是**质量优先**策略：QQ 音乐只给整行 LRC，程序会继续试网易云拿 YRC 真逐字。想固定用 QQ 音乐，在主菜单「歌词」页或托盘「歌词源」里选「QQ 音乐优先」。

**Q：会不会泄露账号？**
不登录、不保存账号密码 / `MUSIC_U` / Cookie、不上传播放记录。只把歌名和艺人发给公开歌词接口，歌词文本缓存在你自己的电脑上。

**Q：会不会被当成外挂封号？**
不注入游戏、不读游戏内存、不改游戏文件、不模拟按键，只是一个普通置顶窗口，和 Discord / Steam 覆盖层同类。**不要**为了显示歌词去关闭或绕过任何反作弊。带反作弊的网游按项目约定不做图形层钩子。

**Q：杀毒软件报毒？**
打包 exe 可能误报。请在 GitHub Releases 下载、核对 SHA256，或从源码自行构建。

**Q：怎么验证程序没坏？**
```bash
node tools/verify_providers.mjs          # 平台 provider 28 项（离线，CI 也跑）
node tools/verify_menu.mjs               # 主菜单 / 辉光 / 真逐字 32 项
node tools/verify_lyrics.mjs             # 歌词引擎与时间轴 19 项
node tools/verify_autofit.mjs            # 自适应 22 项
node tools/verify_preview.mjs            # 视觉预览页 29 项
python tools/verify_window_fit.py        # 真实窗口是否跟随前台游戏（需 app 运行）
python tools/p0_electron_check.py        # 透明窗像素判定
```

## 十、卸载

安装包版：Windows「设置 → 应用 → 卸载」。绿色版：直接删 exe。配置与歌词缓存在 `%APPDATA%\glasslyrics\`，需要彻底清理时手动删除；若勾过开机自启，先取消勾选再卸载。
