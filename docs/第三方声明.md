## LRCLIB 使用边界

P1 起，歌词从 [LRCLIB](https://lrclib.net/) 公开接口在**用户本机运行时**拉取：

- 只发送歌名、艺人、专辑、时长；不发送账号、Cookie、播放历史。
- 设置明确的 `User-Agent`；每首歌首次查询一次，之后读本地缓存；`lyricsInFlight` 防止 500ms 轮询造成重复请求。不高频抓取、不批量下载。
- 歌词文本**不进仓库、不进安装包**，只缓存在用户本机 `%APPDATA%\glasslyrics\lyrics-cache\`。
- LRCLIB 为社区贡献数据库，词条可能缺失或含错；本程序查不到时降级为原创演示占位，不保证准确完整。使用者应遵守其服务条款与所在地法律。

## QQ 音乐 / 网易云音乐公开接口的使用边界（v0.6 起）

`app/providers.js` 在**用户本机运行时**访问以下公开文本接口，只传歌名、艺人、专辑、时长：

| 平台 | 接口 | 用途 |
|---|---|---|
| QQ 音乐 | `c.y.qq.com/soso/fcgi-bin/client_search_cp` | 按歌名找 songmid |
| QQ 音乐 | `c.y.qq.com/lyric/fcgi-bin/fcg_query_lyric_new.fcg` | LRC 歌词与 `trans` 翻译 |
| 网易云 | `music.163.com/api/search/get/web` | 按歌名找 song id |
| 网易云 | `music.163.com/api/song/lyric/v1?level=ex&yv=1` | **YRC 真实逐字**歌词 |
| 网易云 | `music.163.com/api/song/lyric` | LRC 与 `tlyric` 翻译兜底 |

边界：

- **不登录、不保存账号 / 密码 / `MUSIC_U` / Token / Cookie**。请求里的 `appver=3.1.39; os=pc` 只是网易云公开的客户端版本标识（用于让 web 接口返回 `yrc`），不是身份凭证；`Referer` 头同理。
- 不抓音频、不下载歌曲、不批量遍历曲库；每首歌首次查询一次，之后读本机缓存；`lyricsInFlight` 防止 SMTC 轮询重复请求。
- 歌词文本**不进仓库、不进安装包**，只缓存在用户本机 `%APPDATA%\glasslyrics\lyrics-cache\`；缓存带版本号，策略升级后自动重拉一次。
- 制作信息（署名 / 版权）会被过滤，不作为歌词展示；翻译只在平台提供时显示。
- 这些是**非官方公开接口**，平台可能随时调整或限制。程序用三级源 + 缓存 + 失败降级应对，界面明确标出当前来源；不保证长期可用或内容准确。
- 仅供个人学习研究。使用者应自行遵守各平台服务条款与所在地法律，不得分发歌词文本或用于商业用途。

## 关于「参照 DangoMusic」的协议边界

v0.3 起，歌词的视觉与动画按 jar 的真实规格复刻。做法是：

- 读取 jar 内**明文 GLSL 着色器**，理解算法（SDF 圆角、13-tap 降采样、指数曝光热芯白化、边缘折射色散）；
- 用 `javap` 查看类字段、方法签名与字节码常量，取得默认参数（配色 `#F7E1D7`、辉光四色、0.3 强度 / 0.5 半径、8fps 摆动、160ms 砸入曲线、0.3s 淡入）；
- 用 HTML / CSS / JavaScript **独立实现**这些行为。

**未做的事**：没有把 DangoMusic 的任何 `.class`、Kotlin 源码或 GLSL 文件内容复制进本仓库；没有反编译后改写其代码；没有引用其 Firebase 配置。着色器文件本身不入库，只在 `docs/技术方案.md` 里用文字描述算法。

参数与算法规格属于事实观察，不构成 GPL 意义上的代码复制。但为稳妥，本项目仍选择 MIT 自有代码 + 完全独立实现，并保留此说明以备审查。若后续需要引入任何 GPL 项目的代码片段，必须先重新评估协议兼容性。
