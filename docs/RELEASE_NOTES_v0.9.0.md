## GlassLyrics v0.9.0 — 跨游戏液态玻璃歌词覆盖层

独立透明置顶窗口，把 DangoMusic 的液态玻璃歌词观感带到**任意** Windows 游戏上。不注入游戏进程、不读内存、不抓音频，只用 Windows 自带的 SMTC 媒体接口读"谁在放歌"。

### 下载
- **GlassLyrics Setup 0.9.0.exe** — 安装版（推荐，可选安装目录、建快捷方式、开机自启开关）
- **GlassLyrics-Portable.exe** — 绿色便携版，双击即用，不写注册表

### 本版内容
- 网易云 YRC **真逐字**时间轴 / QQ 音乐 LRC + 翻译，自动降级 + 本地缓存
- 液态玻璃主菜单（7 个分区）、字形发散辉光（无矩形底板）
- 漂浮歌词 3–6 行可调，每行独立漂移方向/速度/透明度/字号
- 歌词自由拖动定位、侧栏宽/行距/字重/不透明度可调
- 全部全局热键可自定义（含可选的全局播放控制）
- QQ/网易云搜索选歌（换平台歌单）+ 专辑封面
- 自捕捉前台游戏窗口并跟随（DPI 感知，实测贴合误差 1px）
- 性能：暂停零重绘、扫光量化（样式写入 -97%）、60/30 帧上限、低配模式

### 快速上手
1. 装好 QQ 音乐或网易云，播放任意歌曲（QQ 音乐需在 设置→常规→通知 里打开系统媒体控制）
2. 双击 GlassLyrics，进游戏
3. `Ctrl+Alt+P` 打开主菜单；`Ctrl+Alt+H` 显隐歌词；`Ctrl+Alt+B` 切换布局

### 已知限制
- 独占全屏模式（Exclusive Fullscreen）下任何普通置顶窗都不可见，请改用「无边框全屏 / 窗口化」
- 带反作弊的联机游戏请自行判断是否使用覆盖层
- 「去播放」依赖客户端 URL 协议，个别精简版客户端可能唤不醒，歌名会自动复制到剪贴板
